regenerate after any live-routing change. Sources: the v2 server

Policy (V2_DESIGN 5.4): every merged/renamed tool preserves EVERY
constituent's live behavior; every read tool has a live route or a
documented stale-XML refusal reason. File-only tools refuse locked
files with the standard DocumentLocked message, which names the
live alternates (com_save_document / com_close_open_document) and
states that the call has no live route.
