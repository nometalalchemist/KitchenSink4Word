DEPT. 00

What this is actually for

This is the last Word MCP server you will need to install. Nothing else in the category comes close on capability: 219 operations reach every part of a Word document that serious work touches, and the survey further down this page is mostly empty columns. Completeness is only half of it. Your documents stay open in Word while the agent edits them, so each change appears in the window in front of you rather than arriving as a file you have to reload, and there is a backup before every change, made without you asking. Nothing you have written gets lost here.

For the academic

A committee returns the manuscript covered in tracked revisions, and the citation apparatus has to survive the rewrite. The scholarly furniture that other tools trample, from footnotes to the reference list, is first-class here, so an agent can take on the revision pass without breaking any of it.

For legal, compliance & HR

Contracts, policies, and case files live in Word, and every edit needs an author attached. Edits here can be written as tracked changes, comparing two versions works the way Word itself does it, and redaction actually removes the text, then verifies that it is gone.

For the Word power user

For anyone whose documents are too important to gamble with. Watch the edit land in your own open Word window, take it back with a single Ctrl+Z if you don't like it, and know there was a backup before anything was touched. You keep the cursor; the agent does the typing.

JUST IN New in this version Five things this release changed

The whole list, no release notes required.

  • Fewer tools, and your agent stops guessing. v1.6 had 189 tools with a lot of overlapping names, and agents burned time and tokens picking between them. Version 2 rebuilds everything as 108 tools under one consistent grammar that covers more ground than before, not less. The agent picks right the first time and spends your session on the document instead.
  • Starts light, stays light. A fresh session loads a small core instead of the whole toolbox, and reaches for the specialty shelves only when your task actually needs them. Your assistant keeps more of its attention on your document, and none of the old capabilities went anywhere.
  • Live editing you can leave running. Several agents can now work an open document without colliding, and a Word dialog waiting on a human gets noticed and reported, instead of leaving your agent hanging.
  • Fifty edits, one pass, nothing drifts. Ask for a view of the document and every paragraph comes back with a stable address, so the agent can point at the exact spot it means even after the text shifts. Then the batch editor lands dozens of changes in one pass that either all succeed or leave the file untouched. No more edit number thirty-seven landing on the wrong paragraph.
  • Comment back and forth with your AI. Leave a comment in Word the way you would for a colleague, and the agent reads it, does the work as tracked changes, and replies in the thread. (Preview.)
DEPT. 01

Why this exists

An AI agent once needed fifteen minutes to edit twenty table cells in a Word document. Not because the agent was slow, but because every Word MCP server on the market was missing something. One couldn't delete a table column. Another had no footnotes. A third couldn't touch a table of contents. Installing all three still couldn't do the job.

So instead, this got built: one server with everything. The twenty-cell edit now takes one call and finishes in twenty milliseconds. Your agents will simply never know the struggle.

Almost nobody tells you the size of the bite. Here is ours, measured: small to start, growing only when a task needs a specialty pack, and the exact numbers are on the tiles below.

DEPT. 05

Installation

Pick the line that describes you. Most people are the first one.

Easiest

Using Claude Desktop? One double-click.

Download the installer bundle from the latest release and double-click it, or drag it into the Claude Desktop window. Desktop adds it as an extension and the sink is connected. Nothing to type, nothing to configure.

Download the .mcpb bundle →

One-time requirement: uv on your PATH, which the bundle uses to start the server.

One command

Using Claude Code? Paste this.

One line in a terminal and you are done. It fetches and runs the server for you, so there is nothing to install first.

$ claude mcp add word -s user -- uvx kitchensink4word
For developers: pip, uvx, source, other MCP clients

Install the package and point any MCP client at the executable:

$ pip install kitchensink4word

Then in any client's config: {"mcpServers": {"word": {"command": "kitchensink4word"}}}. Running from a clone works the same way; point the command at the word-mcp executable in the clone's virtual environment. Full setup, including the sandbox options, is in the README.

Windows. File-based tools need no Word installation; the Word-app tools (TOC refresh, PDF, proofing…) use a local Microsoft Word.

🛡️

Engineered Not to Corrupt

You know the morning: the manuscript is due, Word opens, and there is a dialog offering to "repair" your file. That morning is what this whole server is built to prevent. Before any change, a backup is made automatically. Every save is checked before it replaces your file, so a bad write cannot take the original with it. And everything the edit doesn't touch, from equations to textboxes, passes through exactly as it was, byte for byte. Two full stress campaigns and a shelf of long, heavily formatted real manuscripts, and Word has never once offered to repair anything this server saved.
