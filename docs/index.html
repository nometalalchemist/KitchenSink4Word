DEPT. 00

What this is actually for

Plenty of tools can write a paragraph into a .docx file. This catalog exists for the work nobody else solved: editing real Word documents, live in the window, one undo step per call, with merge-aware table surgery, citations, footnotes, and the table of contents handled as first-class fixtures, edits written as tracked changes, redaction with verification, and publication style conversion. It was built for people whose documents are too important to lose.

For the academic

A committee returns the manuscript covered in tracked revisions, and the citation apparatus has to survive the rewrite. Citations, footnotes, cross-references, APA parity checks, and the table of contents are first-class here, so an agent can take on the revision pass without breaking any of it.

For legal, compliance & HR

Contracts, policies, and case files live in Word, and every edit needs an author attached. Edits here can be written as tracked changes, document compare runs Word-native, and redaction actually removes the text, then verifies that it is gone.

For the Word power user

For anyone whose documents are too important to gamble with. Every save is atomic and validated, a timestamped backup precedes each change, and live editing keeps the document open in Word, one Ctrl+Z step per call, with the cursor untouched.

DEPT. 01

Why this exists

An AI agent once needed fifteen minutes to edit twenty table cells in a Word document. Not because the agent was slow, but because every Word MCP server on the market was missing something. One couldn't delete a table column. Another had no footnotes. A third couldn't touch a table of contents. Installing all three still couldn't do the job.

So instead, this got built: one server with everything. The twenty-cell edit now takes one call and finishes in twenty milliseconds. Your agents will simply never know the struggle.

DEPT. 04

Installation

① GET THE FIXTURE

$ pip install kitchensink4word

② CONNECT THE PLUMBING (Claude Code)

$ claude mcp add word -s user -- ^ <python-scripts-dir>\word-mcp.exe

Windows. File-based tools need no Word installation; the seven COM tools (TOC refresh, PDF, proofing…) use a local Microsoft Word. Full setup in the README.
